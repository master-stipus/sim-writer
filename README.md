# sim-writer

Программа для записи контактов на SIM-карту с помощью модема **Huawei E173** и утилиты `gammu` (старые контакты будут удалены).

## Настройка и использование

1. Запишите контакты в CSV-файл:
   ```
   Дарт Вейдер,+79099099999
   Магистр Йода,+71112223333
   ```
   **Называйте контакты короткими именами!** Записать имя из **26** символов я не смог.
2. Установите `gammu`:
   ```bash
   sudo apt update
   sudo apt install gammu
   ```
   Команды могут отличаться в зависимости от системы или дистрибутива.
3. Запишите конфигурацию в `~/.gammurc`:
   ```toml
   [gammu]
   port = "/dev/ttyUSB0"
   connection = "at"
   ```
4. Подключите модем с SIM-картой и сделайте резервную копию контактов:
   ```bash
   gammu backup backup.txt
   ```
5. Очистите SIM-карту от текущих контактов:
   ```bash
   gammu clearall
   ```
6. Запустите скрипт `main.py` для создания файла с новыми контактами:
   ```bash
   python3 main.py --backup backup.txt --contacts contacts.csv
   ```
   В папке со скриптом будет создан `contacts.txt`. Проверьте его на адекватность.
7. Запишите новые контакты на SIM-карту:
   ```bash
   gammu restore contacts.txt
   gammu getallmemory SM
   ```
8. Танцуйте джигу семь дней подряд, как Старик Макгакет.
